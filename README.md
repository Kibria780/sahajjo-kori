# 🤝 সাহায্য করি (Sahajjo Kori)

**সবার জন্য উন্মুক্ত AI মেন্টর** — Hasan-এর উদ্যোগে।

যেকোনো নৈতিক প্রশ্ন করো, AI মেন্টর বাংলায় উত্তর দেবে। ভালো উত্তরগুলো এক ক্লিকে Facebook পোস্ট ফরম্যাটে কপি করে শেয়ার করা যায়।

🌐 লাইভ: https://kibria780.github.io/sahajjo-kori/

## ফিচার
- ❓ প্রশ্ন করো → AI মেন্টরের বাংলা উত্তর
- 📂 বিষয়ভিত্তিক ক্যাটাগরি (পড়াশোনা, ব্যবসা, প্রযুক্তি, স্বাস্থ্য...)
- 📘 এক ক্লিকে Facebook পোস্ট ফরম্যাটে কপি
- 🔊 উত্তর শুনো (বাংলা ভয়েস)
- 🕘 সাম্প্রতিক প্রশ্নের হিস্ট্রি (তোমার ব্রাউজারে)
- 🛡️ অনৈতিক/ক্ষতিকর প্রশ্নে ভদ্রভাবে না বলে দেওয়া হয়

## AI কীভাবে কাজ করে
1. **Groq API** (ফ্রি কী থাকলে — সবচেয়ে নির্ভরযোগ্য)
2. **Pollinations** (কী ছাড়া ফ্রি)
3. **অফলাইন বার্তা** (সার্ভার ডাউন থাকলে সৎ নোটিশ)

কী শুধু তোমার ব্রাউজারের localStorage-এ থাকে — কোথাও পাঠানো হয় না।
